# Static-analysis waivers — the residual the gates accept, and why.
#
# Two style gates cannot reach zero without either reformatting the whole tree or hiding findings, so
# their residual is waived at a stated number rather than quietly tolerated; three semgrep findings in
# `tools/cdp.py` and `tools/cdp_protocol.py` are justified in writing. Both gates read this file —
# `tools/mac-checks.sh` for the two counts, `tools/semgrep-waivers.py` for the semgrep lines — so
# raising a number or adding a line is a deliberate edit with a reason attached, not a silent drift.
#
# What the residual *is*, rule by rule, lives in `.swiftlint.yml` and `.swift-format`, which are the
# configuration for those two tools. This file only says how much of it the gates accept. The caps sit
# a couple of findings above the measured residual (206 and 305 against 208 and 307 after the audit
# enabled `force_unwrapping`, removed the sites it found, and formatted the attachment sources) because
# the two formatters arrive through Homebrew and a patch release can word a diagnostic differently; the
# slack is there for that drift, not for new code. A change that pushes either count past its cap fails
# the gate and has to justify the new number here.
#
#   swiftlint waiver: <count>       the gate fails when the run reports more than this many findings
#   swift-format waiver: <count>    the same, over authored Swift only
#   semgrep waiver: <rule id> <path suffix>
#                                   a finding that stays visible — there is no `nosemgrep` — matched on
#                                   rule id *and* path, because a count cannot tell a justified finding
#                                   from a new one: fixing one and introducing another would leave the
#                                   total unchanged.
swiftlint waiver: 208
swift-format waiver: 307

# `tools/cdp.py` and `tools/cdp_protocol.py` drive a headless Chrome on loopback and nothing else.
# `require_loopback_host` refuses any endpoint that is not 127.0.0.1, localhost or ::1 before a socket
# is opened, the URL scheme is pinned to `http` and built only from validated values, and the reply is
# read with a bound — so the two findings below describe what the scanner cannot see, and each site in
# those files says what it cannot.
semgrep waiver: javascript.lang.security.detect-insecure-websocket.detect-insecure-websocket tools/cdp_protocol.py
semgrep waiver: python.lang.security.audit.dynamic-urllib-use-detected.dynamic-urllib-use-detected tools/cdp.py
