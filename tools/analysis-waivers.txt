# Static-analysis waivers — the residual the gates accept, and why.
#
# One file, because this is the only place a gate reads an accepted finding from. It used to carry a
# count for each style gate as well; the audit drove both to zero (`swiftlint` from 206 findings and
# `swift-format` from 306), and gates 5 and 6 of `tools/mac-checks.sh` now run `--strict` against zero
# rather than against a recorded number. What is left here is the semgrep findings below, which
# are justified in writing because the scanner cannot see the control that answers them.
#
# The style residual *was*, rule by rule, described in `.swiftlint.yml` and `.swift-format`. Those two
# files are still the configuration for their tools; the caps are gone because the debt is.
#
#   semgrep waiver: <rule id> <path suffix>
#                                   a finding that stays visible — there is no `nosemgrep` — matched on
#                                   rule id *and* path, because a count cannot tell a justified finding
#                                   from a new one: fixing one and introducing another would leave the
#                                   total unchanged.
# `tools/cdp.py` and `tools/cdp_protocol.py` drive a headless Chrome on loopback and nothing else.
# `require_loopback_host` refuses any endpoint that is not 127.0.0.1, localhost or ::1 before a socket
# is opened, the URL scheme is pinned to `http` and built only from validated values, the target list is
# read to `MAX_TARGET_LIST_BYTES`, and a websocket frame — and the total of a fragmented message — is
# refused past `MAX_FRAME_BYTES`. So the two findings below describe what the scanner cannot see, and
# each site in those files says what it cannot. (This note used to claim "the reply is read with a
# bound" while the frame length was unbounded, which overstated the control; AUDIT-0087 added the cap.)
semgrep waiver: javascript.lang.security.detect-insecure-websocket.detect-insecure-websocket tools/cdp_protocol.py
semgrep waiver: python.lang.security.audit.dynamic-urllib-use-detected.dynamic-urllib-use-detected tools/cdp.py
